# Restaurant Landing Page

A responsive restaurant landing page built with React, Vite, and Tailwind CSS. It includes a hero section, service cards, promotional banners, and a carousel. Scroll animations use AOS.

[View the live demo](https://restaurant-project-puce.vercel.app/)

## Run locally

```sh
git clone https://github.com/hkermanin/Restaurant-project.git
cd Restaurant-project/restaurant
npm ci
npm run dev
```

Open the local URL printed by Vite.

## Project structure

- `restaurant/src/App.jsx` assembles the landing page.
- `restaurant/src/components/` contains the page sections and carousel.
- `restaurant/src/index.css` contains the app's global styles.

## Build and preview

From the `restaurant/` directory:

```sh
npm run build
npm run preview
```
